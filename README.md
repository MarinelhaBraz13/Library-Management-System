# Library Management System

## Project Description

This project is a Library Management System developed for the J2EE course.

The system helps manage books, users, borrowing, and returning books.

## Technologies Used

- Java
- JSP
- Servlet
- JDBC
- MySQL
- HTML
- CSS
- Bootstrap
- Apache Tomcat
- Eclipse

## Main Features

- User Login
- Admin Login
- Student/Member Login
- Add Book
- Edit Book
- Delete Book
- Search Books
- Filter Books
- Borrow Book
- Return Book
- View Available Books

## Database

Database name:

library_management

The database SQL file is located in:

database/library_management.sql

## How to Run

1. Install Java and Apache Tomcat.
2. Open the project in Eclipse.
3. Create the MySQL database named library_management.
4. Import database/library_management.sql into MySQL.
5. Configure the database connection.
6. Run the project using Apache Tomcat.
7. Open the application in a web browser.

## Project URL

http://localhost:8080/LibraryManagement/
